## 3. 数据库账号与 shadow 库

```sql
-- 实际动作（容器初始化由 MYSQL_* 环境变量自动完成业务库与业务账号）：
CREATE DATABASE IF NOT EXISTS cex_shadow;
GRANT ALL PRIVILEGES ON cex_shadow.* TO 'cex'@'%';
GRANT ALL PRIVILEGES ON cex.* TO 'cex'@'%';
FLUSH PRIVILEGES;
```

- 业务库 `cex` + 业务账号 `cex/cex_dev_123`：由 compose 的 MYSQL_DATABASE/MYSQL_USER/MYSQL_PASSWORD 自动创建
- `cex_shadow`：**踩坑后手动补建**——`prisma migrate dev` 报 P3014（业务账号无建库权限，Prisma 需要 shadow database），补建后在 schema.prisma datasource 声明 `shadowDatabaseUrl = env("SHADOW_DATABASE_URL")`
