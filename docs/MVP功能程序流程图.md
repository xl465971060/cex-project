# MVP 功能程序流程图集

> **配套文档**：《[交易所MVP-做与不做及最小流程.md](交易所MVP-做与不做及最小流程.md)》——每个流程图覆盖该功能情况表的**全部分支**，分支边上标注「情况n」对应原文档情况表编号，便于核对遗漏。
>
> **图例**：圆角框 = 开始/结束；菱形 = 判断/分支；矩形 = 处理动作；虚线 = 异常/旁路入口。
>
> **覆盖范围**（对应 MVP 决策总表中 ✅ 的 9 个模块）：
> 1. 账户与身份（注册/登录/忘记密码/KYC/2FA/安全项修改）
> 2. 充值（扫块入账/错链人工处理）
> 3. 现货交易（下单/撮合/撤单/行情）
> 4. 提现（用户申请/人工审核与打款）
> 5. 记账与对账（账务入口/日终对账）
> 6. Admin 后台（操作审计/交易对配置）
> 7. 邮件通知

### 3.2 撮合流程（限价单 / 市价单分支）

覆盖情况：5.3 表 环节「撮合中」#8~#10、「成交」#12~#13

```mermaid
flowchart TD
    S([撮合引擎取出队首订单]) --> A{"订单类型?"}
    A -->|"限价 GTC"| B{"对手最优价可成交?<br/>买: 出价≥卖一 / 卖: 要价≤买一"}
    B -->|"否"| B1{"剩余数量>0?"}
    B1 -->|"是"| B2["进入订单簿挂单<br/>状态=已接受"] --> R
    A -->|"市价 按金额"| P["取对手最优档"]
    P --> Q{"盘口仍有量<br/>且冻结金额未耗尽?"}
    Q -->|"是"| Q1["按当前档价成交部分<br/>双边记账+扣手续费"]
    Q1 --> Q2["累计扣减冻结金额"]
    Q2 --> P
    Q -->|"否 盘口吃空"| Q3["剩余冻结金额解冻退回<br/>状态=已成交(可能部分)"] --> R
    B -->|"是"| C["成交: 量=min(订单剩余, 档位量)<br/>双边生成成交记录(execId幂等)<br/>记账: 买加币扣钱 / 卖加钱扣币<br/>各自扣手续费 · 情况12/13"]
    C --> D{"订单还有剩余量?"}
    D -->|"否"| E["状态=完全成交"] --> R
    D -->|"是"| B
    B2 --> R
    E --> R
    R["推送: 订单回报/成交记录/行情更新"] --> Z([结束])
```

> 记账兜底：任何时刻发现负余额（理论上一期模型不会发生，因先冻结后成交）→ 立即冻结账户 + 告警人工处理（情况14）。
